สิ่งที่ต้องมีและวิธีเปิด

1 · ไฟล์โมเดล ONNXแปลงจาก checkpoint ครั้งเดียว ได้ไฟล์ราว 190 MB (ไม่อยู่ใน git)
2 · เบราว์เซอร์รุ่นใหม่Chrome หรือ Edge 113 ขึ้นไปจะใช้ WebGPU ได้ (เร็ว) เบราว์เซอร์อื่นใช้ WebAssembly บน CPU (ช้ากว่าแต่ใช้ได้)
3 · อินเทอร์เน็ตครั้งแรกหน้าเว็บโหลดไลบรารี onnxruntime-web และฟอนต์จาก CDN ตัวโมเดลกับภาพอยู่ในเครื่อง
4 · หน่วยความจำRAM ว่างราว 1–2 GB ระหว่างโหลดโมเดล
  1. แปลงโมเดล (ทำครั้งเดียว ที่โฟลเดอร์โปรเจกต์ ต้องติดตั้ง onnx ก่อน) 
    pip install onnx onnxscript onnxruntime
python export_onnx.py
# ได้ไฟล์ web/model/pet_multitask.onnx
  2. วิธีที่แนะนำ: เปิดเว็บเซิร์ฟเวอร์ไฟล์ธรรมดาที่โฟลเดอร์โปรเจกต์ หน้านี้จะโหลดโมเดลให้อัตโนมัติ 
    python -m http.server 8000
# แล้วเปิด http://localhost:8000/web/inference.html
  3. หรือเปิดไฟล์ตรง ๆ (ดับเบิลคลิก web/inference.html) แล้วกดปุ่ม "เลือกไฟล์โมเดล" ด้านล่างเพื่อชี้ไปที่ไฟล์ .onnx เบราว์เซอร์ไม่อนุญาตให้หน้าแบบ file:// อ่านไฟล์เองโดยอัตโนมัติ

ข้อควรรู้

  1. ผลอาจต่างจาก Python เล็กน้อย

    หน้านี้เขียนการย่อภาพแบบ Bilinear ของ PIL ใหม่ในเบราว์เซอร์ แต่ตัวถอดรหัส JPEG ของเบราว์เซอร์ต่างจากของ PIL ค่าตัวชี้วัดจึงอาจคลาดจาก evaluate.py ราวหลักทศนิยมที่ 3

  2. ความเร็ว

    WebGPU ใช้เวลาราวภาพละ 0.1–0.5 วินาที (ขึ้นกับการ์ดจอ) WASM บน CPU ราว 1–3 วินาที การประเมิน test ทั้งชุดด้วย WASM อาจใช้เวลาเป็นชั่วโมง ให้ตั้ง "จำกัด" เป็น 200–500 ภาพเพื่อดูแนวโน้มก่อน

  3. โมเดลตอบได้แค่ 37 สายพันธุ์

    ภาพที่ไม่ใช่หมาหรือแมว หรือสายพันธุ์อื่น จะถูกทายเป็นหนึ่งใน 37 สายพันธุ์เสมอ แม้ความมั่นใจจะสูง

  4. ภาพถูกบีบเป็นสี่เหลี่ยมจัตุรัส

    เหมือนตอนเทรน ภาพแนวนอนหรือแนวตั้งจะถูกยืดก่อนเข้าโมเดล แล้ว Mask จะถูกยืดกลับให้ตรงกับภาพเดิมตอนแสดงผล

  5. ความเป็นส่วนตัว

    ภาพและโมเดลถูกประมวลผลในแท็บนี้เท่านั้น ไม่มีการอัปโหลด

เครื่องมือ: ONNX Runtime Web 1.22.0 · โมเดล: best_model_resnet50.pth (epoch 10) แปลงด้วย export_onnx.py
